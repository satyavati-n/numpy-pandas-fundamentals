# NumPy & Pandas Fundamentals

A beginner-friendly Python learning repository covering the fundamentals of **NumPy and Pandas**, two essential libraries used in Data Analysis.

This repository contains practical Python examples, CSV datasets, and exercises to develop data manipulation and analysis skills.

## Technologies Used

- Python
- NumPy
- Pandas
- CSV



## NumPy Topics Covered

- Introduction to NumPy
- Creating NumPy arrays
- Array indexing and slicing
- Array operations
- Mathematical functions
- Reshaping arrays
- Broadcasting

## Pandas Topics Covered

- Introduction to Pandas
- Series and DataFrames
- Reading CSV files
- Data selection
- Filtering data
- Handling missing values
- GroupBy operations
- Merging datasets
- Data cleaning




## Learning Objective

The goal of this repository is to build a strong foundation in Python libraries used in Data Analytics and prepare for practical data analysis projects.
